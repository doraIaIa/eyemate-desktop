# UI Inventory and Acceptance Notes

## Employee Transparency

Done when:
- The user can distinguish local personal data from organization aggregate data.
- Camera is optional and independently controlled.
- Unlinking an organization does not transfer personal data.
- Opt-out state is not exposed to managers.

## IT Admin

Done when:
- The console contains only identity/device/license/application-management data.
- No health, symptom, camera or individual wellbeing fields appear.
- Check-in is bucketed, not real-time presence.
- Rollout and rollback are version-management operations only.

## HR / EHS Insights

Done when:
- Cohort under privacy threshold is suppressed.
- Every metric displays denominator, coverage, period and methodology version.
- Missing data is shown as unknown.
- No individual drill-down exists.
- Copy avoids causal, medical and productivity claims.

## Campaign

Done when:
- Campaigns use approved templates and bounded settings.
- Employee preview and privacy notice are mandatory.
- Opt-out is mandatory.
- HR cannot see who opted out or ignored a prompt.
- Small cohorts cannot generate analytics.

## EyeMate Program Implementation & Participation Report

Done when:
- Report verifies implementation evidence and document authenticity.
- It explicitly disclaims legal, ISO, HSE and medical certification.
- It includes methodology version, coverage and limitations.
- QR verification checks report ID, document hash, issuer, issue/revocation state and methodology version, not compliance.

## Privacy Audit

Done when:
- Individual, small-cohort, real-time and differencing queries are blocked.
- Allowed aggregate queries are audited.
- Export follows the same policy as dashboard queries.
